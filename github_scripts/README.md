# Утилиты для быстрой работы с GitHub (ghps / ghpl)

В этой папке находятся скрипты для автоматизации повседневных операций с Git. Они позволяют в одну команду стягивать обновления или коммитить и отправлять свои изменения.

## Описание скриптов

### `ghps` (Push)
Скрипт для быстрой отправки ваших изменений в удаленный репозиторий.
* **Проверки:** Убеждается, что вы находитесь внутри Git-репозитория.
* **Умный коммит:** Если есть изменения (включая новые неотслеживаемые файлы), он автоматически добавляет их (`git add -A`) и создает коммит с сообщением `Auto commit from ai script`.
* **Push:** Отправляет изменения на GitHub.
* **Безопасность:** Если измененных файлов нет, скрипт просто завершает работу, ничего не отправляя.

### `ghpl` (Pull)
Скрипт для быстрого получения изменений.
* **Проверки:** Убеждается, что вы находитесь внутри Git-репозитория.
* **Pull:** Забирает последние изменения из удаленного репозитория (`git pull`).

### `setup_aliases.sh`
Вспомогательный скрипт. Он автоматически и безопасно добавляет команды `ghps` и `ghpl` в ваш системный файл настроек `~/.bashrc`, чтобы вы могли вызывать их откуда угодно.

---

## Установка (Настройка алиасов)

Чтобы вам не приходилось каждый раз писать полный путь к скриптам, рекомендуется настроить алиасы (короткие команды).

1. Находясь в этой папке, запустите скрипт установки:
   ```bash
   ./setup_aliases.sh
   ```
2. Примените новые настройки терминала:
   ```bash
   source ~/.bashrc
   ```

---

## Как использовать

**Если вы настроили алиасы (Рекомендуемый способ):**
Просто перейдите в папку любого вашего git-репозитория и напишите:
* Отправить все изменения:
  ```bash
  ghps
  ```
* Стянуть обновления:
  ```bash
  ghpl
  ```

**Если алиасы не настроены:**
Вы можете вызывать скрипты по их полному или относительному пути из любой папки проекта:
```bash
~/app/github_scripts/ghps
~/app/github_scripts/ghpl
```
